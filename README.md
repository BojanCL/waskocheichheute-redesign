# Redline · FoodKreator · Neugestaltung (Entwurf)

Entwürfe für waskocheichheute.ch, den Redline-Shop und foodkreator.ch (FoodKreator AG). Nur zur internen Abstimmung, alle Seiten sind `noindex, nofollow`.

- `waskocheichheute-welten/` – waskocheichheute.ch im aktuellen Design. Einstieg: `index.html` (Werkstatt mit allen Seiten aller drei Websites)
- `waskocheichheute-shop/` – Shop (shop.waskocheichheute.ch) im gleichen Design. Daten in `assets/daten.js`, erzeugt mit `werkzeug/daten_bauen.py` aus dem Shop-Prototyp. Warenkorb nur im Browser, keine Bestellung.
- `foodkreator/` – foodkreator.ch: Produktentwicklung und Produktion für Firmen und Privatpersonen, Ansprache «Sie»
- `waskocheichheute/` – graue Wireframes (Inhalt und Struktur)

Shop und foodkreator.ch nutzen Zeichnungen und Grundgestaltung aus `waskocheichheute-welten/assets/` (art.js, gerichte.js, welten.css, start.css, page.css).
Alle Illustrationen sind Vektorgrafiken im Code. Reines HTML, CSS und JavaScript, kein Build-Schritt.
